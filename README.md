# 《弹幕破韧者 // CORE BREAKER》— 极简 Boss 战弹幕生存原型

一个基于 **HTML5 Canvas 2D + 原生 JavaScript** 打造的极简 Boss 战弹幕生存原型（单文件零依赖，双击即可在浏览器运行），面向**游戏 AI 策划 / 战斗数值调优**演示。

- **在线试玩地址（开启 GitHub Pages 后可用）**：`https://lzq-ovo.github.io/core-breaker-boss-demo/`
- **完整设计文档**：[游戏完整说明文档.md](./游戏完整说明文档.md)

## 核心亮点

1. **高风险-高收益战斗闭环**
   - **Boss 韧性机制**：Boss 有韧性条期间减伤 `80%`（仅承受 `20%` 伤害），`5s` 未受击自动回满；打空韧性触发 `1.5s` 破韧眩晕（承受 `100%` 全额伤害），并有 `30%` 概率全图随机掉落血包（回 `20%` HP）或护盾（抵挡一次伤害）。
   - **完美冲刺（Just Dodge）**：空格冲刺无敌帧前 `0.12s` 撞击弹幕触发 `0.25s` 全局子弹时间、额外回复 `2` 点 MP，并反击一道高额削韧（`10` 点）的追踪波。
   - **两档右键激光**：撞弹积累 MP（上限 `10`），`5` MP 释放普通激光（`50` 伤），购买“双生激光”后攒满 `10` MP 可释放 `120` 伤强化激光（击溃 `50%` 韧性，低于 `30` 直接击碎）。
2. **双关卡与局内外成长**
   - **Stage 1（CORE GUARDIAN）**：`200 HP / 100 韧性`，二阶段追踪、螺旋弹幕、蓄力激光与随机预警陨石。
   - **Stage 2（PHANTOM SENTINEL）**：`400 HP / 120 韧性`，瞬移后留下半透明 `PHANTOM` 分身协同发弹，二阶段追加 V 字双道交叉激光。
   - **全屏三栏式大厅**：左侧常驻**战术补给商店**（主动清弹技能、叠加属性、玻璃大炮/磁力核心/双生激光高风险词条），第 1 关通关支持**肉鸽三选一强化**（弹道+1 / 伤害×2 / 红色三角自动追踪僚机）。
3. **AI 策划工具链**
   - **DAT.GUI 实时调参面板**：动态调节 Boss 血量、移速、弹幕速度、玩家血量与冲刺无敌帧。
   - **AI 托管 Bot 与 5 局一键压力测试**：内置势场排斥避险 Bot，可现场自动对战或一键后台跑测 5 局输出**通关率、平均耗时、受击、破韧次数与 DPS** 报告。

## 基础操作
- `W A S D` / `方向键`：移动
- `鼠标左键`（点击或长按）：朝鼠标方向发射弹幕
- `Space`（空格）：冲刺（半透明无敌帧，撞击弹幕蓄 MP）
- `鼠标右键`：MP ≥ 5 时朝鼠标方向发射高能激光
- `E` 键：释放商店解锁的“清除周围弹幕”技能
